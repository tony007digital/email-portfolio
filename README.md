# Email Development Samples

Production HTML email samples spanning regulated pharma, affiliate/B2B, and
legacy retail work.

**Live site:** https://tony007digital.github.io/email-portfolio/

Each folder contains a self-contained `index.html` email template:

- `aimovig1/` — Pharma patient-nurture email (Veeva Systems)
- `mylocal_flirt/` — Dating-affiliate re-engagement email
- `gallery/` — Legacy desktop-era newsletter (pre-mobile-responsive standards)

View any template rendered via the live site link above, or open the
`index.html` file directly in a browser. Full source is visible in this repo.

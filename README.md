# Email Dev Career Hub

Source for https://email-dev-career-hub.netlify.app/. Netlify deploys this branch (`career-hub`) on every push.

Updated every Friday from the "Email Job Market Data" Google Sheet by a scheduled task. Only the data block in `index.html` (between `/* ---------- data:` and `/* ---------- helpers`) plus the date stamp, jobs note and footer change each week.
